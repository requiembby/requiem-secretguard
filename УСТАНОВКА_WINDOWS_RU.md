# REQUIEM SecretGuard v0.3 — установка на Windows

## Новый Chrome Extension (без Python)

1. Полностью распакуй `REQUIEM_SecretGuard_v0.3_Full.zip` (или `REQUIEM_SecretGuard_v0.3_Chrome_Extension.zip`).
2. Открой **Google Chrome** и вставь в адресную строку: `chrome://extensions`.
3. Справа вверху включи **Режим разработчика** (Developer mode).
4. Нажми **Загрузить распакованное расширение** (Load unpacked).
5. Выбери **папку `extension`**, внутри которой находится файл `manifest.json`.
6. Нажми значок «пазл» в Chrome и закрепи расширение REQUIEM SecretGuard.
7. Открой **свой** веб-сайт, нажми на расширение, подтверди разрешение и выбери **Run security scan**.

Проверка работает только для активной вкладки, где ты нажала на кнопку, и анализирует встроенный и доступный с того же сайта JavaScript. Результаты не являются доказательством взлома или полной безопасности.

## Проверяем расширение на искусственных примерах

1. Если у тебя ещё запущен старый SecretGuard v0.2 в PowerShell, закрой его (`Ctrl+C` в терминале). Иначе порт 8765 будет занят.
2. Открой папку `requiem-secretguard` **из v0.3**.
3. Дважды нажми `start_secretguard_windows.bat`.
4. В Chrome открой `http://127.0.0.1:8765/extension-demo`.
5. Нажми кнопку расширения, поставь галочку о разрешении и нажми **Run security scan**.
6. Должны появиться **две тестовые находки**: Stripe (Critical) и GitHub (High). Это вымышленные данные.
7. По желанию нажми **Export JSON**. Значения ключей в JSON не попадают.

Если Chrome показывает сообщение, что расширение нельзя запустить на текущей странице, убедись, что открыта обычная вкладка `http://` или `https://`, а не `chrome://extensions`.

## Сканирование локальных папок

Папки на диске по-прежнему проверяются в отдельном веб-интерфейсе по адресу `http://127.0.0.1:8765/` или через командную строку. Расширение браузера не получает доступ к твоим файлам на диске.

Проект не отправляет секреты в облако. Сканировать следует только собственные проекты или сайты, на проверку которых у тебя есть разрешение.
